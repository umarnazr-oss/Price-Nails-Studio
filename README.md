# Price Nails Studio

## Добавление фотографий

1. Запустите сайт командой `npm run dev`.
2. Откройте в браузере `http://localhost:5173/admin`.
3. Введите пароль из локального файла `.env`.
4. Добавьте название и фотографию JPG, PNG или WebP размером до 8 МБ.

Загруженные фото сразу появляются на главной странице и в галерее. В админ-панели можно удалить загруженное фото. Подпись к загруженной фотографии показывается одинаково на французском, английском и русском сайтах.

Фотографии и список галереи хранятся в `public/uploads`. Сохраняйте резервную копию этой папки. Файл `.env` содержит пароль администратора: не публикуйте его и не добавляйте в Git.

## Запуск для посетителей

Для production нужен хостинг, который запускает Node.js и сохраняет файлы между перезапусками:

```text
npm run build
npm start
```

На хостинге задайте секрет `ADMIN_PASSWORD` (не короче 16 символов) и включите постоянное дисковое хранилище для `public/uploads`.
